## Run it

Requires Node 22 or later. No dependencies.

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes exactly one line to `/output/entry.txt` — the entry. The
output is deterministic: run it twice and you get the same line both times.

## The entry

> Approved. Clean diff, green tests, and a quiet feeling this code will outlive us all.
